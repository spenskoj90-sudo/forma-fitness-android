# FORMA approved mockup — photographic hero asset

The dashboard background photo in app/src/main/res/drawable-nodpi/forma_hero.jpg
is a small cropped visual extracted from the Owner-supplied and approved
"Фитнес-приложение FORMA — путь к силе.png" design reference.
It is bundled locally (no network loading) and used only as decoration.

The figure is not a demonstration of correct exercise technique.
Exercise-specific guidance continues to use the original text cues and
errors in the application. Do not reuse the sample bench-press photograph
for unrelated floor press, standing or bodyweight exercises.

Visual acceptance on Infinix Zero 30 and Realme C31 is still required.
Do not equate artifact/build CI success with visual acceptance.
